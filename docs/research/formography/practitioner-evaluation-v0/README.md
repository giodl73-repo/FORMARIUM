# Formography practitioner evaluation V0

Status: `protocol_ready_recruitment_pending`

This packet tests whether the name **Formography** helps practitioners
understand a fixed governed-mapping method better than **Governed Property
Graph**. It does not test representational novelty: the comparative slices
already show that a generic scoped property graph can encode the complete
authored contract.

The study is blinded at the method-body level. Participants see the same method
text and the same three cases. Only the displayed heading changes according to
the frozen randomization table.

## Files

- `practitioner-protocol-v0.json`: frozen design, measures, and gates.
- `participant-method-card-v0.md`: invariant method body.
- `participant-case-packet-v0.md`: three standalone tasks.
- `participant-response-form-v0.csv`: header-only result template.
- `randomization-v0.csv`: balanced 12-slot assignment.
- `moderator-guide-v0.md`: administration and privacy rules.
- `scoring-contract-v0.json`: fixed field values and case scoring anchors.
- `recruitment-handoff-v0.md`: neutral invitation, eligibility, and consent.

No participant has been recruited and no result is recorded. Model agents and
synthetic personas cannot fill a participant slot. Field promotion, renaming,
Formarium promotion, and human-evidence claims remain unauthorized.
