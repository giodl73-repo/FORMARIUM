# {{METHOD_LABEL}}

Use this method to map a bounded question without turning one view into a
universal ontology.

1. State the question and boundary.
2. Identify the primary factorization and any useful alternatives.
3. Record typed relations together with the context in which each relation
   holds.
4. Preserve the source and review authority for every governed claim.
5. Keep unresolved states explicit rather than choosing a silent default.
6. When presenting a smaller view, declare what the projection omits or
   compresses.

A projection helps a reader navigate the governed source. It does not replace
that source or acquire independent authority.
