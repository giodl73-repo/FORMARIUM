# Formography Independent Coding V0 Result

Date: 2026-08-18
Status: promotion threshold not met

## Design

Three isolated coders from different model families received:

- the frozen object contract and output schema;
- six canonical source files;
- current reference, relation, and assurance records;
- no authored formographs, comparison results, or other coder output.

Each coded all three cases before adjudication.

## Threshold results

| Gate | Result | Evidence |
|---|---|---|
| Same canonical owner in every case | **Fail** | C1/C2 use exact entry IDs; C3 says `Factorium reference method` |
| Majority on required core categories | Pass | every category populated; C1/C2 retain complete canonical roots |
| Authority and projection loss preserved | Pass | 9/9 case records |
| Graph sufficiency answered | Pass | 9/9 say generic property graph is sufficient |
| Majority-supported essential extensions | **Fail** | partial overlap in access and quantity; no stable decision-case majority |
| Terminology advantage | **No result** | Formography 1, governed property graph 1, neither 1 |

## Meaningful agreement

All coders independently retained:

- bounded forms and multiple views;
- source authority rather than method-owned domain truth;
- visible projection loss;
- unresolved or missing state;
- ordinary property-graph compatibility.

The representation result is now stronger: all nine independent case codings
say a generic property graph is sufficient.

## Meaningful disagreement

The coders did not converge on the smallest domain extension:

| Case | C1 | C2 | C3 |
|---|---|---|---|
| Access Authorization | decision/enforcement correlation | grant lifecycle and propagation | policy authority and delegation context |
| Amount and Composition | quantity basis contract | volume-additivity convention | physical state, volume, and closure |
| Choice and Selection | alternative-state outcome cell | alternative-generation boundary | recommendation/selection authority |

These are not cosmetic names for one obvious field, especially in the
decision case.

The terminology comparison also provides no advantage:

- C1: `neither`, confidence 78;
- C2: `formography`, confidence 62;
- C3: `governed-property-graph`, confidence 90.

Ordinal preferences are retained rather than averaged.

## Verdict

`PAUSE_FIELD_PROMOTION_REVISE_AND_RERUN_INDEPENDENT_PROTOCOL`

The governed-method-profile thesis survives, but repeatability and explanation
advantage are unproven. Formography is not ready to be presented as a field,
rename, or simpler term.

## Next test

Pre-register V1 rules for:

1. exact owner identity versus authority class;
2. semantic agreement for core categories;
3. equivalence classes for domain extensions;
4. structured-failure comparison;
5. explanation-cost observation rather than preference alone.

V0 coder records remain immutable negative and disagreement evidence.
