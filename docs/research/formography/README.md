# Formography Research Module

Status: proposed field may proceed with targeted narrowing

This module tests whether **Formography** is a defensible name and method for
systematically mapping forms through factors, relations, contexts, boundaries,
and evidence without imposing one universal ontology.

The module follows the research-module pattern adapted from `C:\src\rmm`:

1. frame a falsifiable working claim;
2. separate local evidence from external prior art;
3. record claims, comparisons, and evidence tests in machine-readable files;
4. retain nulls, collisions, and reasons to narrow or abandon the proposal;
5. promote papers or naming changes only after source and role review.

No artifact in this module renames Factorium, promotes Formarium, establishes a
new academic field, or claims novelty.

The exact term `formography` has one confirmed prior academic use: a 2021
TU Dresden workshop proposed it for ethnographic study of forms in practice.
The module therefore requires explicit acknowledgment and methodological
contrast before any public field claim.

The first comparative encoding slice is in `comparative-slice-v0/`. Its
Access Authorization case shows that a generic scoped property graph can
retain all ten predeclared features. Formography therefore survives this case
only as a candidate governed method profile, not as a distinct graph
representation.
