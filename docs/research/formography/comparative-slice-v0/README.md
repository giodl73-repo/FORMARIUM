Date: 2026-08-18
Status: first representative case complete

## Question

What does a candidate formograph retain beyond a conventional concept map and
a generic scoped property graph when all three encode the same governed
Factorium case?

## Result

The concept map retains the focus question, primary decomposition, alternative
views, and labeled relationships, but not exact digest custody, review
bindings, qualifier contracts, boundary rules, unresolved state, or projection
loss as native requirements.

The generic property graph retains all ten predeclared features. This disproves
any claim that Formography is needed because graphs cannot encode the
information.

The candidate formograph also retains all ten features, but makes every one a
required, fail-closed method invariant. The invalid fixture is rejected with
`FG-PROJECTION-LOSS-MISSING`; the generic graph profile has no equivalent
native requirement.

Current conclusion:

`SURVIVES_AS_GOVERNED_METHOD_PROFILE_NOT_DISTINCT_GRAPH_REPRESENTATION`

This is one case, not a field proof. Two additional cross-domain cases and
independent coding remain required.
