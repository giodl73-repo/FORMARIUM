# Thermodynamic System, State, Process, and Phase Research Note

Date: 2026-08-15
Status: source-grounded candidate synthesis

## Finding

The reusable structure is:

```text
selected system + boundary + surroundings
  -> allowed matter and energy transfers
  -> state described by properties under a model
  -> process and path between states
  -> phase inventory and possible phase transitions
```

A boundary is an analytical selection, not necessarily a rigid wall. Open,
closed, and isolated labels summarize permitted exchanges. State describes the
current condition; path retains how it changed. IUPAC defines a phase by
uniform chemical composition and physical state and a phase transition by a
change in phase nature or phase count under changed external conditions.

Solid, liquid, gas, and specialist phase names remain examples. The canon owns
boundary, exchange, state, path, uniformity, phase count, interface, and transition.
