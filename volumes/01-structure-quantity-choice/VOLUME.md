# Factorium Volume Prototype 01

Title: **Structure, Quantity, and Choice**

Status: ready for external usability testing

Selected canonical records and views: **78**

Application guides: **2**, not included in the 78-record count

## Purpose

This prototype tests whether a reader can use Factorium as a table-first
reference rather than as a repository tree. It curates the complete current
record set into a progressive path:

1. learn the root coordinates and factor-role vocabulary;
2. separate identity, change, policy, evidence, and editorial structure;
3. select quantities and their specialized mathematical views;
4. compare information and economic concepts;
5. follow one recursive security composite into prime entries;
6. apply the reference through two Factor Guides.

Chapter order is a publication projection. Canonical identity and source
custody remain in the linked entries and generated catalog.

## How to read

Use one of three modes:

- **lookup** - start from the [generated catalog](../../tables/CATALOG.md) and
  select a headword or family;
- **learn** - follow the chapters below in order;
- **apply** - begin with a [Factor Guide](../../guides/INDEX.md), then follow
  its canonical trace backward.

Every substantial entry should let the reader:

1. select a sense;
2. inspect factors, alternatives, and constraints;
3. choose a specialized view when needed;
4. follow cross-references or visible unresolved candidates;
5. distinguish canonical content from local guide recommendations.
