# FACTOR Pulse

Use this skill for FACTOR development pulses.

## Workflow

1. Read `CONTEXT.md` and `context/waves/PHASES.md`.
2. Read the active wave and target pulse.
3. Implement the smallest complete slice.
4. Preserve packed aliases and strong factored controls.
5. Keep broad NLP and hardware claims outside synthetic evidence.
6. Update docs and pulse status.
7. Run the pulse validation commands and `git diff --check`.
