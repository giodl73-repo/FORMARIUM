# Formography Independent Coding 02 Plan

Date: 2026-08-18
Status: pre-registered rerun plan

## Objective

Rerun independent model coding with V0 records frozen and three ambiguities
removed from the protocol:

- owner reference versus authority class;
- free-text extension equivalence;
- unbounded terminology preference.

## Changes from V0

V1 provides separate exact owner and authority fields, pre-registered extension
and failure taxonomies, per-category codability status, and paired 35-55 word
explanations of the same contract.

## Non-goals

- no V0 record amendment;
- no authored formograph exposure;
- no correct extension answer supplied;
- no human or practitioner claim;
- no field or rename promotion from model agreement alone.

## Decision

Pass only the predeclared thresholds. If extension categories or terminology
still fail, pause rather than create V2 immediately.
