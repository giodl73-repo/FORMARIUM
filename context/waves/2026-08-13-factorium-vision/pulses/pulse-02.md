# Pulse 02: General Factor-Role Vocabulary

## Goal

Define the small platform-neutral vocabulary used to describe how factors
participate in a decomposition before any OO, Rust, database, cloud, or
organizational mechanism is selected.

## Planned changes

- Define pivot, capability, component, variant, state, policy, relationship,
  boundary, context, constraint, and derived view.
- Distinguish identity, variation, ownership, mutability, authority, and
  interpretation.
- Record dependencies and many-to-many role assignments.
- Add cross-references and counterexamples.
- Review the vocabulary through the expanded Factorium roles.
