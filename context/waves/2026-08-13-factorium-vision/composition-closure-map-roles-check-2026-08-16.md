# Composition Closure Map - Factorium Role Review

## Artifact identification

Artifact type: identified-result visualization specification for the generated
Proof Set Composition Lab.

Domain signals: typed directional graph projection, evaluative scope display,
unique-node layout, SVG and HTML accessibility, negative state rendering,
result provenance, and simulation claim control.

| Role | Why selected |

## Synthesis

Roles reviewed: 8
P1 blockers: 0  |  P2 issues: 0  |  P3 notes: 24

Verdict: APPROVED

Top finding: The map must consume and repeat the identified result rather than
reconstructing graph meaning from presentation markup.

Cross-role consensus: Direction, node uniqueness, stopped boundaries, scope
semantics, and source identity must be explicit in both visual and non-visual
forms; the map remains a projection into the book, never another authority.

## Amend

1. In `Exact map record`, bind every record to the result SHA-256 and digest-
   matched payloads, rejecting incomplete or duplicate data.
2. In `Direction and scope semantics`, distinguish typed traversal, evaluation
   ownership, frontier, and conflict without relying on color.
3. In `Interface`, provide complete HTML records and preserve the stage audit
   and book route under deterministic failure behavior.

The reviewed contract already incorporates all three amendments. No critical
or major finding remains open.
