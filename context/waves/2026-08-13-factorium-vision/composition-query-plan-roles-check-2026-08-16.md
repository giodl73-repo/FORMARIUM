# Composition Query Plan - Factorium Role Review

## Artifact identification

Artifact type: live pre-execution projection of explicit Composition Lab
controls in a generated proof-edition interface.

Domain signals: compositional semantics, directional relation mapping,
reference navigation, partial-form validation, source identity, display
profiles, and evidence-boundary language.

## Role selection

| Role | Why selected |
|---|---|
| Compositional Semantics Steward | The receipt must not imply that selected controls already form a valid closure. |
| Reference Architecture Editor | The panel must support rather than displace the staged form and book route. |
| Reference Lexicographer | Human labels and nearby concepts must remain exact and distinguishable. |
| Evidence & Claims Editor | Control completeness cannot become a usefulness or validity claim. |

| Research Integrity & Provenance | Payload and result identities must remain reconstructable and separate. |

| Schema Implementer | Pure record, diagnostics, invalidity, and ordering must be independently reproducible. |

## Synthesis

Roles reviewed: 8  
P1 blockers: 0 | P2 issues: 0 | P3 notes: 24

Verdict: APPROVED

Top finding: The plan must summarize only explicit controls; it cannot predict
closure or inherit executed-result identity.

Cross-role consensus: exact payload custody, direction/loss separation, and
permanent no-execution language keep the panel useful without creating a
second semantic or evidentiary authority.

## Amend

1. Separate canonical relation direction from displayed traversal direction in
   both pure records and Full metadata.
2. Define `control-complete` as syntax and selection coverage only; expose
   exact diagnostics for partial controls.
3. Preserve the complete `sim-22` interface on runtime absence or rejection
   and mint no plan identity.

The reviewed contract incorporates all amendments. No P1/P2 finding remains.
