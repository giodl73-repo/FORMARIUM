# Synthetic Dual Literal Lookup Plan

Date: 2026-08-17

Status: proposed freeze; execution not started

Campaign: `SUJ-06`

Evidence class: deterministic dependent literal-lookup rehearsal

## Product question

SUJ-05 shows that one literal query provides a first foothold for nine of ten
question tasks but exposes two intended families for only two. Before asking
people—or software—to decompose a question, test the strongest already-frozen
literal control: the union of both independent queries authored for every
SUJ-02 task before any of the later route results existed.

The conditional candidate is an ephemeral **dual literal lookup**: two
independent Search panels with unchanged rankings and a canonical-family
identity comparison. It is not question decomposition. It generates no query,
merges no rank, selects no family, assigns no relation, and computes no closure.

## Frozen execution

Reuse the ten SUJ-04 `have-question` tasks and both queries already frozen in
SUJ-02. Against exact `sim-44`, inspect the first ten ownership groups from
each query independently, then compute only their set union by canonical family
identity. Retain every task and both result orders.

## Hypotheses and admission gate

1. At least 8/10 tasks expose two intended canonical families across the union.
2. For at least 6/10 tasks, query two adds an intended family absent from query
   one's first ten groups.
3. Independent lists and the identity union remain visibly distinct from
   semantic decomposition, relation selection, closure, and recommendation.

Both numeric gates must pass before interface work. Otherwise preserve the
null, keep `sim-44`, and conclude that alternate literal phrasing is not the
missing multi-concept bridge.

## Boundaries

No merged ranking, query generation, automatic selection, inferred relation,
URL task state, persistence, network, canonical write, content change, or
profile-conditioned behavior is permitted. Mechanical coverage is not reader
recognition, relevance, comprehension, usefulness, preference, or demand.
