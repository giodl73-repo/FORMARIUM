# Pointer Entry Concordance Plan

Date: 2026-08-18
Status: active internal simulation plan

## Objective

Make repeated structural leaves clickable without manufacturing canonical
entries. Build one generated concordance layer in `sim-52`, beginning with 20
explicitly admitted cross-domain labels including `actor`.

## Product value

Reader: someone who encounters a factor label inside a formula and wants to
know where else it is used.

Job: move from one leaf to all of its exact structural occurrences, compare
the owning contexts, and return to authored Tables.

Current friction: factor labels are visually meaningful but inert; search
mixes prose mentions with structural use; creating a full entry merely to make
a term clickable would overstate editorial maturity.

Product change: one Terms index, generated Pointer Entry pages, and links from
exact code occurrences. Evidence now can establish deterministic coverage,
route integrity, boundaries, and browser mechanics. External readers are still
needed for findability, comprehension, and usefulness claims.

## Scope and stop

Admit exactly 20 registry labels. Scan only selected Table records and exact
rendered code expressions. Preserve `sim-51` as the optional naming snapshot;
return `sim-52` to the Factorium interface while the name remains undecided.

Stop before canonical promotion, prose auto-linking, synonym inference,
stemming, relation creation, reference-format changes, or search-ranking
claims. A registry label with zero occurrences fails the render.
