# Synthetic Manual Concept Basket Plan

Date: 2026-08-17

Status: complete; candidate rejected; see `SYNTHETIC-MANUAL-CONCEPT-BASKET-RESULT.md`

Campaign: `SUJ-05`

Evidence class: deterministic interface feasibility rehearsal

## Reader problem and smallest candidate

A person with a question can name it in Compose, but seven of ten frozen
question routes have no exact authored starter and cannot reach their intended
concept families without an invented semantic step. Earlier lexical rehearsal
suggests Search may be a safer bridge, but it has not tested whether one query
exposes enough explicit concepts to form a useful working set.

The smallest candidate is an **ephemeral manual concept basket** attached to
Search. A person may collect up to five canonical Table families from the
existing ownership-group results, inspect the untyped set, open its exact
Table links, copy it, or clear it. The basket selects nothing automatically,
adds no relation, computes no closure, and produces no Guide or recommendation.

## Frozen portfolio

Reuse exactly the ten `have-question` assignments from SUJ-04 and the first
already-frozen literal query for each task from SUJ-02. Run against clean
`sim-44`. For each assignment:

```text
enter first query
-> inspect first ten ownership groups
-> explicitly collect intended visible families (maximum five)
-> inspect the untyped reading set
-> clear
```

No retry, synonym expansion, inferred seed, reordered result, post-result
target change, or profile-conditioned behavior is permitted.

## Frozen hypotheses and stop rule

1. At least 8 of 10 assignments expose two or more intended canonical
   families in the first ten ownership groups.
2. Every discoverable intended family can be explicitly collected without
   changing search ranking or publication ownership.
3. The set remains visibly untyped and cannot be mistaken for semantic
   closure, recommendation, or a Factor Guide.

The candidate is admitted only if hypothesis 1 passes and the mechanic retains
one owner, no sensitive persistence, no canonical write, and no automatic
semantic choice. Otherwise record the null result and stop. If admitted, mint
a new internal simulation; preserve `sim-44` exactly.

## Evidence boundary

Browser mechanics may establish result visibility, explicit collection,
limits, links, labels, clear behavior, overflow, storage absence, and unchanged
search order. They cannot establish concept recognition, relevance,
comprehension, usefulness, trust, satisfaction, preference, or demand. The
campaign is dependent on earlier authored tasks and is not independent reader
evidence.
