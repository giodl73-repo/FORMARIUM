## Product value contract

| Field | Decision |
|---|---|
| Reader | A reader entering `power`, or one who needs the application procedure for an opened Table |
| Jobs | Choose the intended power meaning; reach an already-authored handoff without scanning the entire entry |
| Trigger | CAD-02's failed `power` packet and `value`'s clipped handoff observation |
| Existing owners | Work/Energy/Power; Electrical Quantity; Organization/Authority; Force/effective influence/coercion |
| Candidate | `sim-49`; no Table, relation, search-index, or ranking change |
| Evidence now | Exact routing, source/render coverage, capture-boundary classification, responsive mechanics, and custody |
| Evidence later | Reader recognition, correct route choice, comprehension, usefulness, and task completion |
| Stop | One exact chooser and, only if frozen audit thresholds pass, one generated handoff action |

`PWR-01` freezes four non-equivalent routes in
`fixtures/lexical-closure/power-meaning-chooser-01.json`. Activation is exact
after established normalization. It must remain inactive for `powers`,
`power factor`, `electrical power`, `organizational power`, and other extended
queries because those queries already retain context for literal search.

No new organizational-power owner is admitted. Formal authority and effective
influence or coercive capacity already have distinct owners; the chooser must
not collapse them. Literal rankings, the 185-record search index, canonical
metadata, Table content, relations, and prior editions remain unchanged.

`HVA-01` freezes all 53 canonical entry files. For each, record whether an
authored Selection procedure, Review procedure, or Use contract exists;
whether its heading begins inside or after CAD-01's 5,000-normalized-character
capture boundary; whether the rendered heading has an anchor; and whether
`sim-49` supplies a top navigator route.

The comparison clip is an evaluator-instrument boundary, not a browser
viewport and not reader evidence. Add a generated `Use this Table` action only
if at least 40 entries contain an authored handoff and at least 10 fall after
the clip. Never create an action where the source lacks a qualifying heading.
Do not move, duplicate, or rewrite authored content.

Render clean `sim-49` only after a clean implementation commit. Require exact
routes, exact target resolution, byte-identical search index, zero missing
local targets, live 390-pixel Edge presentation, full audit custody, and all
repository checks. Claim no reader or competitive superiority evidence.
