# Composition Result Reconciliation - Factorium Role Review

## Artifact identification

Artifact type: read-only projection of an identified Composition Lab result
into an executed-request summary in the generated proof edition.

Domain signals: compositional semantics, exact relation mapping, result-state
language, finite-budget numeracy, reference navigation, source custody, and
profile-responsive presentation.

## Role selection

| Role | Why selected |
|---|---|
| Compositional Semantics Steward | Admission and non-admission labels must remain structural. |
| Reference Architecture Editor | The summary must orient readers without displacing books, map, route, or audit. |
| Reference Lexicographer | Decision vocabulary must distinguish stopped, unresolved, and conflicting records. |
| Evidence & Claims Editor | Result mechanics cannot become validity or reader-success claims. |
| Benchmark Numeracy Checker | Selected and classified counts and four budget ledgers must reconcile. |
| Mapping Integrity Auditor | Canonical relation direction must survive reverse traversal display. |
| Research Integrity & Provenance | The projection must inherit source and result identity without minting another. |
| Reference Practitioner | A reader needs a fast account of what happened to each explicit choice. |
| Schema Implementer | Exhaustiveness, invalidity, ordering, and reason classes must be reproducible. |
