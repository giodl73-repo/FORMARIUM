# Root Table

Status: candidate

## Orientation

The Root Table collects recurring coordinates that appear across many
factorizations. They are practical starting points, not a claim that every
subject has one final decomposition or that these concepts are metaphysically
indivisible. A root may be treated as prime in one view and factored further
in another.

## Root coordinates

| Coordinate | Governing question | Typical role |
|---|---|---|
| [Identity](../roots/identity.md) | What is it, and what makes it the same one? | Distinguishes and tracks |
| [Boundary](../roots/boundary.md) | What is inside, outside, or crossing? | Defines inclusion and interface |
| [Context](../roots/context.md) | Under what circumstances does it apply? | Qualifies interpretation |
| [State](../roots/state.md) | What condition is it in now? | Locates a configuration |
| [Relation](../roots/relation.md) | How is it connected to something else? | Structures dependence and association |
| [Agency](../roots/agency.md) | Who or what can act? | Locates capability and responsibility |
| [Transformation](../roots/transformation.md) | What changes, and by what transition? | Connects prior and resulting states |
| [Constraint](../roots/constraint.md) | What limits, requires, or forbids? | Restricts valid combinations |
| [Purpose](../roots/purpose.md) | Why does it exist or matter? | Orients evaluation and design |
| [Time](../roots/time.md) | When, for how long, and in what order? | Locates sequence and duration |
| [Measure](../roots/measure.md) | How much, how well, or with what confidence? | Makes comparison explicit |
| [Possibility](../roots/possibility.md) | What alternatives or future states remain open? | Exposes options, uncertainty, and risk |

## Five root families

These families are navigation projections. They overlap and do not impose a
single inheritance hierarchy.

| Family | Orientation | Common coordinates |
|---|---|---|
| **Being** | What exists and how it is distinguished | identity, boundary, state |
| **Relating** | How things are connected and situated | relation, context, boundary |
| **Changing** | What happens across states | agency, transformation, time |
| **Governing** | What directs, limits, or evaluates action | purpose, constraint, measure |
| **Knowing** | What can be distinguished, supported, or anticipated | identity, context, measure, possibility |

## Reusable root factorizations

| Headword | Candidate factorization | Derived output or emphasis |
|---|---|---|
| Thing | `identity x kind x boundary x state @ context` | distinguishable entity |
| Event | `agency x action x object x time @ context = outcome` | occurrence |
| System | `purpose x boundary x components x relations x behavior @ environment` | organized whole |
| Change | `prior state x trigger x transformation x resulting state ! invariants` | transition |
| Decision | `possibilities x criteria x evidence x constraints x authority = choice` | selected alternative |
| Control | `subject x action x object x policy x context x enforcement = decision` | governed action |
| Claim | `proposition x source x evidence x scope x confidence` | warranted assertion |
| Value | `beneficiary x need x outcome x cost x risk` | assessed worth |
| Organization | `purpose x agents x roles x authority x resources x processes x interfaces` | coordinated institution |
| Design | `problem x context x forces x possibilities x tradeoffs x constraints = form` | selected structure |

Terms without links in this table are visible unresolved candidates for later
entries. The rows are starting grammars, not definitions that every use must
adopt.

## Constraints

- No root coordinate is mandatory merely because it appears here.
- Coordinates may overlap; an editor must explain any distinction important to
  the current view.
- Derived outputs such as choice, outcome, and form are not independent inputs.
- A domain entry may replace a broad root with a narrower canonical entry.
- A root treated as prime in one table may be composite in another.
- Families support browsing; typed graph relationships remain canonical.
