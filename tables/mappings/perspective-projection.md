# Perspective and Projection Mapping

Status: candidate Mapping Table

Primary family: Mapping Table

Canonical headword: [Model, Representation, and Simulation](../entries/model-representation-simulation.md)

Canonical senses: `model`, `representation`, `simulation-result`

## Governing question

How does a source subject/model become a purpose-specific target view, and
which distinctions, identities, and uncertainties are lost or derived?

## Mapping contract

| Field | Required record |
|---|---|
| source | exact subject, model, representation, version, and boundary |
| perspective | stakeholder/reader, question, purpose, and admissible detail |
| selection | included, excluded, merged, summarized, and derived content |
| target | view identity, representation contract, and intended use |
| direction/cardinality | source-to-target direction and one/many relation |
| loss | omitted distinctions, uncertainty, ordering, provenance, and alternatives |
| reconstruction | exact, approximate, ambiguous, impossible, or not attempted |
| review | applicability, consistency, stale-source, and misuse checks |

## Projection examples

| Source | Target | Retained | Declared loss |
|---|---|---|---|
| full Factor Table | Compact reader profile | title, orientation, decisive contrasts | detailed factors, provenance display, alternatives hidden under disclosure |
| system description | stakeholder view | selected concerns and model kinds | other viewpoints and cross-view detail |
| simulation runs | summary result | declared outputs and uncertainty | run-level variation unless linked |
| working graph | flattened Factor Guide | selected concepts and evaluated checks | traversal alternatives and unresolved frontier unless explicitly retained |

## Integrity checks

1. Verify source and target identities and mapping direction.
2. Account for every source field as retained, transformed, merged, excluded,
   unresolved, or out of target scope.
3. Reconstruct only where an inverse contract exists; otherwise expose loss.
4. Compare alternate perspectives without treating one as the subject itself.
5. Invalidate or revise the target when source identity or interpretation
   changes beyond the declared compatibility rule.
