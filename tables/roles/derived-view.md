# Derived View

Status: candidate

## Sense: computed projection

A derived view is an output calculated, classified, summarized, or projected
from source factors and a derivation rule.

`derived view = derive(source factors, rule)`

Preserve the source factors when the result must be explained, recomputed, or
audited. Treating severity, priority, access decisions, or display names as
independent observations hides their dependencies.
