# Component

Status: candidate

## Sense: constituent role

A component is a factor treated as a part assembled into, contained by, or
owned by a larger whole.

`whole := components x relationships ! assembly constraints`

Use the role when part-whole structure matters. Do not use it merely because
one concept references another; associations, capabilities, and contexts need
not be components.

Contrasts with: [Capability](capability.md),
[Relationship](../roots/relation.md).
