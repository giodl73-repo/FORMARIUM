# Factor Status and Completeness Evidence Table

Status: candidate Evidence Table

Primary family: Evidence Table

Canonical headword: [Decomposition Modes and Combination Contracts](../entries/decomposition-modes-combination-contracts.md)

Canonical senses: `epistemic-status`, `completeness-contract`, `projection`,
`decomposition-mode`

## Governing question

What supports each factor and the claimed boundary of the decomposition, and
which factors or frontiers remain assumed, derived, omitted, or unresolved?

## Factor evidence table

| Status | Required binding | Does not establish |
|---|---|---|
| observed | source entity/event, observer/system, method, context, time, record | accuracy, representativeness, or causal role |
| measured | measurand, model, procedure, system, value/unit, uncertainty | truth outside measurement scope |
| asserted | exact proposition, asserting agent/authority, basis, scope, version | independent support |
| assumed | proposition, purpose, necessity, alternatives, sensitivity, owner | correctness because the model runs |
| inferred | premises, rule/model, assumptions, conclusion, uncertainty | direct observation |
| simulated | model, implementation, inputs, run, result, interpretation | subject behavior or validation |
| derived | source factors, derivation rule, version, loss, reproducibility | independent evidence |
| unresolved | exact question, missing evidence, owner, next test, stop reason | absence or falsity |

## Completeness evidence

| Claim | Required evidence | Mandatory limitation |
|---|---|---|
| exhaustive | closed inclusion rule, full member coverage, exclusivity/overlap policy, remainder test | only under declared rule and boundary |
| purpose-complete | reader question, sufficiency criteria, passed tests, known exclusions | not ontology completeness |
| partial | admitted subset and selection rationale | omitted factors remain possible |
| open | extension rule and current frontier | no final member count |
| truncated | finite budget, exact stop reason, untraversed frontier | result is incomplete by construction |
| residual-present | reconciliation basis, residual identity, uncertainty, disposition | residual cause remains unresolved unless separately supported |

## Review procedure

1. Bind every factor to one or more status records without collapsing them.
2. Preserve source entities, activities, agents/authorities, versions, and
   derivation chains.
3. Mark status changes as new reviewed records; do not overwrite assumptions
   with observations silently.
4. Test the exact completeness claim against inclusion, coverage, overlap,
   budget, residual, and alternate-decomposition cases.
5. Publish unresolved frontiers and projection loss beside the readable result.
