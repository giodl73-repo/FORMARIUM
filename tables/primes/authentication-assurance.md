# Authentication Assurance

**Resolution status:** Unlinked subfactors are `unresolved-candidate`.

**Tagline:** Confidence that the presented subject identity was established by
an acceptable process.

| Candidate factors | Use when | Watch for |
|---|---|---|
| credential-type x factor-count x verifier-strength x freshness | Comparing authentication ceremonies | Assuming every second factor adds equal assurance |
| identity-proofing x authenticator-binding x authentication-event | Separating enrollment from each login | Collapsing proofing and authentication |

Authentication assurance is evidence about an identity claim, not the identity
and not the authorization decision.

**Maturity:** `candidate`
