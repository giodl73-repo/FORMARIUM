# Subject-Object Relationship

**Resolution status:** Unlinked subfactors are `unresolved-candidate`.

**Tagline:** The typed connection between a principal and a protected object.

| Candidate factors | Examples | Watch for |
|---|---|---|
| relationship-type x source x target x validity | owner, member, parent, delegate | Treating relationship names as globally equivalent |
| path x inherited-authority x depth | organizational or graph authorization | Hidden transitive privilege |

Relationships are contextual facts used by policy, not permissions by
themselves.

**Maturity:** `candidate`
