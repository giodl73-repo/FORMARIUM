# Requested Action

**Resolution status:** Unlinked subfactors are `unresolved-candidate`.

**Tagline:** The operation a subject asks to perform.

| Candidate factors | Use when | Watch for |
|---|---|---|
| verb x operation-scope x side-effect-class | APIs and command systems | Using broad verbs such as `manage` as atomic permissions |
| read-write-admin lattice | Coarse product controls | Assuming every operation fits one linear privilege order |

Object type and state constrain which actions are meaningful.

**Maturity:** `candidate`
