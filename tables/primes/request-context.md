# Request Context

**Resolution status:** Unlinked subfactors are `unresolved-candidate`.

**Tagline:** Facts that affect interpretation of a request without defining
the subject, action, or object.

| Candidate factors | Examples | Watch for |
|---|---|---|
| time x network x device x location x risk | Conditional access | Context becoming an unstructured miscellaneous bucket |
| transaction x purpose x consent x emergency-state | Regulated workflows | Context values silently changing meaning across policies |

Context should be typed, sourced, and freshness-bounded.

**Maturity:** `candidate`
