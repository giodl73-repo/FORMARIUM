# Protected Object

**Resolution status:** Unlinked subfactors are `unresolved-candidate`.

**Tagline:** The resource whose state, information, capability, or boundary is
subject to control.

| Candidate factors | Use when | Watch for |
|---|---|---|
| object-type x stable-id x owner x lifecycle-state | Resource-oriented authorization | Encoding policy outcomes into object type |
| data-domain x sensitivity x residency x retention | Information governance | Treating every record as independently governed |

Protected object is often a pivot because action validity, policy scope, and
relationships depend on it.

**Maturity:** `candidate`
