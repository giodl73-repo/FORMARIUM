# Context

Status: candidate

## Sense: interpretive circumstances

Context collects circumstances that change how another factor is interpreted
without necessarily changing that factor's identity.

`context := environment x situation x applicable frame`

Treat context as prime when the relevant frame is fixed. Factor it further
when location, jurisdiction, channel, workload, audience, or surrounding state
changes validity or meaning.
