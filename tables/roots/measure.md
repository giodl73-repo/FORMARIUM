# Measure

Status: candidate

## Sense: explicit comparison

Measure maps an observed subject and property into a value using a stated
method and reference.

`measure := subject x property x method x scale x uncertainty`

Treat measure as prime when the metric contract is fixed. Factor it further
when sampling, aggregation, units, thresholds, confidence, or proxy validity
affects interpretation.
