# Boundary

Status: candidate

## Sense: inclusion and interface

Boundary distinguishes what a view includes, excludes, or permits to cross.

`boundary := inclusion rule x exclusion rule x interfaces @ context`

Treat boundary as prime when scope is already agreed. Factor it further when
ownership, trust, topology, jurisdiction, or lifecycle creates different
inside/outside judgments.
