# Transformation

Status: candidate

## Sense: state-changing operation

Transformation connects a prior state to a resulting state through an action,
process, or rule.

`transformation := prior state x operation x resulting state ! invariants`

Treat transformation as prime when only the transition name matters. Factor it
further when triggers, intermediate stages, reversibility, side effects, or
failure paths affect the result.
