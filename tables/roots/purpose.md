# Purpose

Status: candidate

## Sense: intended reason or end

Purpose states the end toward which an artifact, action, or organization is
oriented.

`purpose := beneficiary x desired outcome x rationale @ context`

Treat purpose as prime when the intended end is agreed. Factor it further when
stakeholders, competing objectives, measures, or stated and actual purposes
diverge.

Related: [Agency](agency.md), [Measure](measure.md),
[Constraint](constraint.md).
