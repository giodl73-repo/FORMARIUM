# Time

Status: candidate

## Sense: temporal position and extent

Time locates an observation, event, state, or obligation in sequence and
duration.

`time := position x duration x ordering @ reference frame`

Treat time as prime when a single timestamp or interval suffices. Factor it
further when recurrence, deadlines, valid time, transaction time, or competing
clocks matter.
