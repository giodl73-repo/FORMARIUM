# SI Defining Constants

Status: candidate Reference Value Table

Canonical headword: [Physical Constant](../entries/physical-constant.md)

Primary family: Reference Value Table

Purpose: provide a compact lookup for the seven exact constants whose fixed
numerical values define the SI.

## Values

| Constant | Symbol | Exact numerical value | Unit | Defines |
|---|---|---:|---|---|
| caesium hyperfine frequency | `Delta nu_Cs` | `9 192 631 770` | `Hz` | second |
| speed of light in vacuum | `c` | `299 792 458` | `m s^-1` | metre |
| Planck constant | `h` | `6.626 070 15 x 10^-34` | `J s` | kilogram |
| elementary charge | `e` | `1.602 176 634 x 10^-19` | `C` | ampere |
| Boltzmann constant | `k` | `1.380 649 x 10^-23` | `J K^-1` | kelvin |
| Avogadro constant | `N_A` | `6.022 140 76 x 10^23` | `mol^-1` | mole |
| luminous efficacy | `K_cd` | `683` | `lm W^-1` | candela |

## Value contract

- Values are exact in the stated SI units.
- They have no numerical-value uncertainty in the SI definition.
- Symbols and units are part of the value.
- The table does not replace the SI Brochure or realization guidance.
- Exact defining status does not make a quantity dimensionless or remove
  experimental uncertainty from measurements that realize a unit.
