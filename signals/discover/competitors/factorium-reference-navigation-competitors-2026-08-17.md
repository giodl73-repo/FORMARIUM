# Factorium Reference Navigation — Competitive Brief

## The primary competitor: none / the status quo

Threat: **HIGH**. The default is not adopting another reference product. A
reader can enter a word in ordinary web search, accept a knowledge panel or top
result, open Wikipedia when the result is topical, and use a thesaurus only
when wording is the problem. Google already presents automatically assembled
topic snapshots and routes onward to web sources
(https://support.google.com/knowledgepanel/answer/9163198). This bundle is
familiar, fast, broad, and requires no explanation of Factorium's model.

Findings:

1. Factorium must earn a new job; “find an entry” alone cannot overcome search inertia.
2. The status quo can answer proper-noun and current-fact questions that Factorium intentionally excludes.
3. Switching cost begins before the first query because readers must understand Tables, Reader, meanings, and factors.
4. A slower result can still win only when it exposes a consequential distinction the familiar tools leave implicit.

## The whitespace

The plausible whitespace is a curated, cross-domain **ambiguity-to-decision
reference**: take ordinary language, preserve multiple plausible meanings,
route each meaning to a stable conceptual owner, expose governing factors and
near-neighbor contrasts, and provide bounded continuation through an authored
closure. This is an inference from the sources below, not a market or reader
claim.

5. Merriam-Webster optimizes word choice through ranked synonyms, similar words, and antonyms, not factor-led evaluation (https://www.merriam-webster.com/thesaurus).
6. OneLook accepts descriptions and returns definitions and related words, making it strong for reverse lookup but not an authored decision closure (https://www.onelook.com/thesaurus/).
7. WordNet explicitly links disambiguated senses with named lexical and semantic relations, making it the closest structural lexical comparison (https://wordnet.princeton.edu/).
8. Wikipedia explicitly treats disambiguation as getting readers quickly to the desired article, while broad-concept articles explain shared conceptual scope (https://en.wikipedia.org/wiki/Wikipedia:Disambiguation).
9. Wolfram|Alpha computes answers from curated data and algorithms rather than merely returning links, making it a strong adjacent comparator for evaluable quantitative tasks (https://www.wolframalpha.com/about).
10. ConceptNet supplies a broad, multilingual semantic graph assembled from several sources; breadth and machine relations are its advantage, not a small authored reader path (https://conceptnet.io/).
11. No reviewed product claims Factorium's exact bundle of sense choice, governing factors, explicit contrast, bounded composition, and loss-declared continuation.
12. That whitespace is only strategic if users encounter questions for which those distinctions change what they do next.

## Table stakes

13. Exact ordinary-language lookup and clear disambiguation are table stakes; Wikipedia documents quick routing as the purpose of disambiguation.
14. Sense separation and labelled relations are table stakes against WordNet, which distinguishes word forms from word meanings and labels relation types.
15. Related-word breadth and useful ranking are table stakes against Merriam-Webster and OneLook.
16. Source and authority visibility are table stakes against curated encyclopedic and computational references.
17. Fast first-screen legibility is table stakes against search; Factorium cannot require graph literacy before showing value.
18. A visible stopping boundary is Factorium's integrity advantage only if it does not feel like an incomplete answer.

## The cost of building the wrong thing

- Building a larger synonym graph competes where WordNet, OneLook, and
  Merriam-Webster already have depth; it also weakens Factorium's concept
  boundary.
- Building an encyclopedia competes with Wikipedia's breadth, source network,
  and editorial scale while displacing the Tables.
- Building an answer engine competes with search and Wolfram|Alpha and invites
  unsupported inference beyond the curated reference.
- Building more UI before proving differentiated task output increases route
  cost without demonstrating product value.
- Therefore the next risk to retire is not content count. It is whether the
  current reference produces a materially different and inspectable output on
  ambiguous concept questions.

## Three amendments

1. **Change:** describe search as “choose a meaning, then inspect the governing
   factors.” **Output change:** the first screen leads with the distinction and
   its owner rather than presenting entry retrieval as the whole job.
2. **Change:** score authored factors, contrasts, stopping boundaries, and
   continuation separately from related-word coverage. **Output change:** a
   competitive result can show differentiated structure without claiming
   general superiority.
3. **Change:** freeze an ambiguity-to-decision portfolio before further
   content or navigation work. **Output change:** the next admitted batch, if
   any, is tied to repeated competitive misses rather than intuition.
