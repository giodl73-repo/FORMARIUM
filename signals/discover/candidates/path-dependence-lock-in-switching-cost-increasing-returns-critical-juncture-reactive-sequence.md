# Path Dependence, Lock-In, Switching Cost, Increasing Returns to Adoption, Critical Juncture, and Reactive Sequence

Status: noncanonical candidate entry draft

[Admission brief](../literature/path-dependence-lock-in-candidate-brief-2026-08-20.md)

## Orientation

This candidate describes historically sequenced mechanisms under which earlier
events condition later options. It rejects generic historical causation and
emergence as owned senses, requiring evidence of a bounded mechanism and
counterfactual alternatives.

## Sense table

| Sense ID | Governing question | Core |
| --- | --- | --- |
| `path-dependence-mechanism` | Which earlier sequence changes later feasible paths through a specified reproducing mechanism? | history-conditioned mechanism |
| `lock-in-state` | Which self-reinforcing configuration persists despite identified alternatives and switching conditions? | persistent contingency |
| `switching-cost` | Which cost of changing from a current arrangement to an alternative is evidenced for whom and when? | transition burden |
| `adoption-increasing-returns` | Which adoption feedback makes an option relatively more attractive as adoption accumulates? | adoption feedback |
| `critical-juncture` | Which bounded choice interval has durable, mechanism-traced downstream consequences? | consequential choice interval |
| `reactive-sequence` | Which event sequence is linked by reactions that condition subsequent events? | reaction-linked sequence |

## Root factorization

Factor initial conditions, alternatives, actors, sequence, mechanism, feedback,
switching cost, time, scope, counterfactual, evidence, and boundary. History,
contingency, and causation are factors or routed owners, not senses.
Factors sharing a sense label are recording dimensions of the selected account,
not duplicate senses.

## Decisive distinctions

Path dependence needs a mechanism, not merely temporal precedence. Lock-in is
not any persistence; it requires alternatives and reinforcement or barriers.
Switching cost is a burden of transition, not proof of lock-in. Increasing
returns concerns adoption feedback; critical juncture a bounded consequential
choice interval; reactive sequence a chain of reactions rather than generic
historical narrative.

## Dependencies and stopping boundary

Require a traceable sequence and stated alternatives. Route generic causal
claims to `causal-reasoning`, emergent phenomena away from this family, and
current operational constraints to relevant domain owners. Do not infer
irreversibility from longevity.

## Selection procedure

Identify the alleged mechanism, specify baseline and alternatives, then test
feedback, transition burden, juncture, or reaction linkage. Record a plausible
non-path-dependent account whenever evidence cannot discriminate.

## Reference Delta

Adds a narrow historical-mechanism vocabulary without converting all history
into causal proof.

## Failure signs

Failure includes using path dependence for any sequence, lock-in without
alternatives, increasing returns without adoption feedback, or emergence as a
synonym.
