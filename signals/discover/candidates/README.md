# Candidate Entry Drafts

These files exercise the full Lexicon entry grammar before canonical
admission. They are not Tables, canonical records, search results, graph
identities, or reader-evidence claims.

A draft may move to `tables/entries/` only after its literature brief,
source/domain review, fixed-point role review, graph and catalog validation,
and recurring reader need all pass.

Validate the complete noncanonical corpus from the repository root:

```powershell
node tools/check_candidate_entries.js
```
