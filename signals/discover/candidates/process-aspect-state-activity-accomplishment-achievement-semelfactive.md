# Process Aspect: State, Activity, Accomplishment, Achievement, and Semelfactive

Status: noncanonical candidate entry draft

[Admission brief](../literature/process-aspect-state-activity-accomplishment-achievement-semelfactive-candidate-brief-2026-08-20.md)

## Orientation

This candidate classifies how a bounded predication unfolds, not what event,
state, process, or lifecycle record exists. It retains the Vendler-style
contrast while treating telicity, culmination, duration, iteration, and
consequent state as diagnostics or factors unless they independently pass a
future governing-question test.

## Sense table

| Sense ID | Governing question | Core |
| --- | --- | --- |
| `aspectual-state` | Which situation is presented as holding without an inherent dynamic progression? | homogeneous holding |
| `aspectual-activity` | Which unfolding is presented as durative without an inherent endpoint? | atelic unfolding |
| `aspectual-accomplishment` | Which extended unfolding is presented as reaching a bounded result? | durative bounded unfolding |
| `aspectual-achievement` | Which change is presented as punctual or near-punctual at its boundary? | bounded change |
| `aspectual-semelfactive` | Which single bounded occurrence is presented without a required resultant state? | atomic occurrence |

## Root factorization

Factor temporal extent, homogeneity, dynamicity, internal stages, endpoint
structure, iteration, result description, viewpoint, and contextual coercion.
Telicity, culmination, and consequent state are factors; they are not senses.

## Decisive distinctions

States need not progress. Activities may continue without reaching an inherent
result. Accomplishments have staged duration plus a described endpoint;
achievements locate change at a boundary; semelfactives are single occurrences
without commitment to a resulting state. The same verb phrase may shift class
with object, adverbial, or viewpoint, so no lexical label fixes the answer.

## Dependencies and stopping boundary

Require a described predication and aspectual evidence. Route entities, actual
process records, lifecycle transitions, temporal ordering, causal results, and
evaluation to their existing owners. Do not add telicity, culmination, or
consequent state as standalone senses.

## Selection procedure

Apply progressive, duration, and completion diagnostics only as defeasible
evidence; then inspect whether the account asserts progression, an inherent
endpoint, boundary change, or a single occurrence. Preserve multiple parses
where context underdetermines aspect.

## Reference Delta

Adds a linguistic-semantic classification layer that can describe records
without replacing state/event/process/lifecycle infrastructure.

## Failure signs

Failure occurs when a verb is assigned one class regardless of context, a
diagnostic is reified as a sense, or the entry claims to classify physical
events independently of description.
