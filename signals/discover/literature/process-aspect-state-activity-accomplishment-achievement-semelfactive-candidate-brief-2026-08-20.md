# Process Aspect — Candidate Brief

## Decision question

Should Lexicon admit aspectual classes for how a predication presents
unfolding, while leaving event and lifecycle ownership intact?

## Bounded thesis

Yes, provisionally. The classes answer a linguistic governing question that
`state-event-transition-process-lifecycle` does not: whether a description
presents holding, open-ended unfolding, extended culmination, boundary change,
or a single occurrence.

## Proposed senses

| Sense ID | Governing question |
| --- | --- |
| `aspectual-state` | Which situation is presented as holding without an inherent dynamic progression? |
| `aspectual-activity` | Which unfolding is presented as durative without an inherent endpoint? |
| `aspectual-accomplishment` | Which extended unfolding is presented as reaching a bounded result? |
| `aspectual-achievement` | Which change is presented as punctual or near-punctual at its boundary? |
| `aspectual-semelfactive` | Which single bounded occurrence is presented without a required resultant state? |

## Candidate contract

Record predication, context, viewpoint, duration, endpoint, result, iteration,
and diagnostics. Treat every diagnostic as defeasible and preserve alternative
readings.

## Existing-owner audit

`state-event-transition-process-lifecycle` owns records of states and
processes; `temporal-organization` owns ordering; causal reasoning owns effects.
This candidate owns only presentation-aspect. Telicity, culmination, and
consequent state remain factors.

## Source matrix

| Source | Contribution | Limitation |
| --- | --- | --- |
| [SEP, Events](https://plato.stanford.edu/entries/events/) | Establishes that event individuation and description are contested. | It is not a complete aspectual taxonomy. |
| [Comrie, *Aspect* publisher record](https://www.cambridge.org/core/books/aspect/4F3BF6D0D0BD30D74FE50A6F8DB514CB) | Supports viewpoint and situation-aspect distinctions. | It does not make diagnostics exceptionless or ontological. |

## Admission gates

Require corpus examples with context-sensitive reclassification and a collision
check. The five senses must remain useful without reifying their factors.

## Counterevidence and limits

Vendler classes are disputed and languages vary substantially. The candidate
makes no claim that every language or physical process instantiates this scheme.

## Disposition

Keep a noncanonical aspectual candidate; do not split telicity, culmination, or
consequent state into senses.
