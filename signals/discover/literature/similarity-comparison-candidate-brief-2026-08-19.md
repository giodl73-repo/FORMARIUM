# Similarity, Difference, Analogy, Equivalence, and Match

## Decision question

Does Formarium need one reader-facing owner for claims that two independently
identified subjects are alike, different, equivalent under a criterion,
analogically mapped, matched, or substitutable for a purpose?

## Bounded thesis

Proceed only as a comparison and correspondence entry. Entity identity,
mathematical identity, arithmetic difference, semantic equivalence, and model
validity retain their current owners.

The thesis is falsified if those existing owners can answer the full comparison
contract without duplicated authority or if similarity, equivalence, analogy,
matching, and substitution cannot survive pairwise distinction.

## Proposed senses

| Sense | Governing question |
|---|---|
| `similarity` | In which declared respects, and by which measure, are these subjects alike? |
| `difference` | After alignment, in which respects do they diverge? |
| `equivalence` | Under which invariant, relation, partition, or purpose are they treated as the same? |
| `analogy` | Which source-to-target mapping supports a structural comparison or tentative inference? |
| `match` | Which correspondence among candidates satisfies the declared rules and constraints? |
| `substitutability` | Can the target replace the source for a declared role and direction? |
| `interchangeability` | Can each replace the other over a declared domain with acceptable loss? |

## Candidate contract

```text
comparison-correspondence-use
  := independently identified subjects
   x representations, versions, context, and purpose
   x compared features, relations, functions, or outputs
   x alignment, normalization, basis, and scale
   x equivalence criterion, invariant, and closure properties
   x similarity or distance measure and direction
   x analogy source, target, mapping, and projected inference
   x match candidates, cardinality, constraints, and unmatched cases
   x substitution direction, preserved properties, tolerated loss, and reversibility
   x difference and match residuals, tolerance, evidence, uncertainty, and counterexample
```

## Admission gates

1. Identify both subjects before comparison.
2. State comparison purpose, respects, representation, alignment, and scale.
3. Select one claim type rather than treating similarity, equivalence, match,
   and substitution as synonyms.
4. For equivalence, state the relation and intended closure properties.
5. For matching, retain candidate sets, cardinality, thresholds, and unmatched
   cases.
6. For substitution, retain direction, preserved properties, loss, and failure
   cases.
7. Retain differences and unmatched remainder as factors of comparison or
   matching rather than creating a separate residual sense.
8. Route identity, formal equality, arithmetic difference, semantic
   equivalence, and model validity to their existing owners.

## Disposition

**PROCEED TO CANDIDATE ENTRY DRAFT; DO NOT ADMIT CANONICALLY.** The source base
supports the distinctions. Canonical admission still requires an entry draft,
fixed-point role review, graph/catalog checks, and a demonstrated recurring
reader lookup need.
