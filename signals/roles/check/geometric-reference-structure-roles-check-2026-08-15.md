# Geometric Reference Structure Roles Check

## Phase 1 - Artifact identification

Artifact type: canonical Factor Table anchor, Diagnostic Table view, three
cross-reference repairs, source review, graph-debt resolution, and proposed
interchange/book registration.

Domain signals: geometry, metrology, motion, coordinate representation,
reference frames, geospatial transformations, trigonometry, units,
uncertainty, and practitioner diagnostics.

## Phase 2 - Role selection

| Role | Why selected |
|---|---|
| Factorization Method Steward | Tests whether object, locus, measure, representation, and frame are genuine pivots. |
| Experimental Methodologist | Audits frozen fixtures, transformations, refinements, tolerances, and comparison conditions. |
| Evidence & Claims Editor | Prevents coordinate agreement or visual similarity from becoming geometric or physical proof. |
| Benchmark Numeracy Checker | Audits units, scale, traversal counts, residuals, epochs, tolerances, and uncertainty. |
| Reference Lexicographer | Point, curve, path, length, shape, angle, coordinates, and frame are easily collapsed. |
| Reference Architecture Editor | Connects geometry, motion, and trigonometry and resolves six graph-debt declarations. |
| Domain Source Reviewer | Metrology, CRS, navigation, and trigonometry claims need authoritative scope. |
| Research Integrity & Provenance | Raw paths, coordinates, transformations, frames, and source conventions must be reconstructable. |
| Equation & Units Auditor | Length, angle, coordinates, metrics, and frames need dimensional and symbol contracts. |
| Mapping Integrity Auditor | Coordinate and frame transformations require direction, domain, authority, and loss disclosure. |
| Reference Practitioner | Readers need a fast route from conflicting geometry to a discriminating test. |
