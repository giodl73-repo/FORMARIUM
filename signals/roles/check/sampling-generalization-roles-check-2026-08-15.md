# Sampling and Generalization Roles Check

## Phase 1 - Artifact identification

Artifact type: canonical Factor Table anchor plus Diagnostic Table view,
research note, cross-reference repairs, and proposed interchange registration.

Domain signals: sampling, survey quality, statistical estimation, experiments,
benchmark splits, causal inference, evidence, source-to-target inference,
reference architecture, and practitioner lookup.

## Phase 2 - Role selection

| Role | Why selected |
|---|---|
| Factorization Method Steward | Tests whether one survey or inferential decomposition is made inevitable. |
| Experimental Methodologist | Separates selection, assignment, analysis, and target-population claims. |
| Data Split & Leakage Auditor | Applies the source-target contract to benchmark corpora and holdouts. |
| Evidence & Claims Editor | Prevents sample size or method labels from licensing broad inference. |
| Benchmark Numeracy Checker | Checks denominators, stage counts, uncertainty, and effective support. |
| Reference Lexicographer | Nine nearby terms must remain quickly distinguishable. |
| Domain Source Reviewer | Statistical and transport claims must retain source conditions and limits. |
| Benchmark Consumer | The diagnostic must work without Factorium-specific internals. |
| Reference Practitioner | The entry must improve a real result review within minutes. |
