# Query-Led Limiting-Condition Repair Roles Check

## Artifact identification

Type: source-backed plan for one existing Diagnostic Table repair.

Domain signals: capacity, queues, dependencies, project schedules, policy and
safety constraints, evidence limitations, navigation, and synthetic query
rehearsal.

## Role selection

| Role | Why selected |
|---|---|
| Factorization Method Steward | The repair must expose alternative pivots rather than one universal limiting factor. |
| Reference Lexicographer | Bottleneck, blocker, constraint, limitation, and critical path are easily confused. |
| Reference Architecture Editor | The repair must route among existing owners without creating another authority. |
| Concept & Taxonomy Boundary Editor | Domain bottlenecks and constraint types could become an open catalog. |
| Evidence & Claims Editor | Internal recurrence and source examples must not become effectiveness claims. |
| Domain Source Reviewer | Schedule, networking, operations, safety, and evidence claims need bounded sources. |
| Reference Practitioner | The owner test must reduce reconstruction for the five recognizable questions. |
| Product Owner | One repaired view must outperform a new anchor, view, relation, or mechanic. |

## Synthesis

Roles reviewed: 8

P1 blockers: 0 | P2 issues: 16 | P3 notes: 8

Verdict: APPROVED

Top finding: the repair must distinguish alternative limiting roles by exact
result, mechanism, and record; `bottleneck` cannot become their shared
canonical identity.

Cross-role consensus: deepen one existing diagnostic, route to existing
owners with untyped links, preserve sim-41, and make no search, relation,
anchor, reader-value, or optimization claim.

## Amendments incorporated

1. Bind critical path and capacity examples to their exact GAO and RFC domain
   scopes rather than universalizing them.
2. Add one discriminating question and required record for all six roles,
   including evidence limitation as a non-operational boundary.
3. Preserve title, owner, senses, sidecar, search mechanics, and historical
   edition custody; require exact five-packet rerun comparison.
