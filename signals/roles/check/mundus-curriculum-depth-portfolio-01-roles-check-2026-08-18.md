# Roles Check: MUNDUS Curriculum Depth Portfolio 01

Artifact type: source-led coverage portfolio and deterministic fixture.
Domain signals: reference architecture, curriculum sampling, evidence rights,
taxonomy boundaries, product value, and research provenance.

## Role selection

| Role | Why selected |
|---|---|
| Experimental Methodologist | Freezes selection, controls, nulls, and processing order before comparison. |
| Reference Lexicographer | Prevents course vocabulary from becoming an unbounded headword list. |
| Concept & Taxonomy Boundary Editor | Separates reusable concepts from named fields, methods, and instances. |
| Reference Architecture Editor | Keeps the ledger derived from rather than competitive with Factor Tables. |
| Evidence & Claims Editor | Bounds what titles, metadata, and internal review can establish. |
| Domain Source Reviewer | Checks course rights, scientific limits, and specialized guidance. |
| Research Integrity & Provenance | Checks exact commits, digests, membership, and reproducibility. |
| Reference Practitioner | Tests whether the campaign can improve a recognizable lookup job. |
| Product Owner | Tests product value, stopping rules, and maintenance cost. |

## Synthesis

Roles reviewed: 9
P1 blockers: 0 | P2 issues: 0 | P3 notes: 27

Verdict: APPROVED

Top finding: half the portfolio is metadata-only, with life/health and
economics/organizations especially thin in record-level evidence.

Cross-role consensus: metadata can prioritize source review but cannot support
concept admission, and null/no-gap results must remain visible.

## Amendments applied

1. Added an explicit metadata boundary to the fixture and checker so all 24
   homepage probes emit no concept-admission candidate.
2. Added a processing-order and null-retention contract so coverage results
   cannot be outcome-selected.
3. Added the product-owner record and surfaced the two thin evidence lanes so
   the portfolio number cannot masquerade as balanced knowledge coverage.
