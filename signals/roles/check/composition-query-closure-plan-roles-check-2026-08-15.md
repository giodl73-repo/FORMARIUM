## Phase 4 -- Synthesis

Roles reviewed: 10
P1 blockers: 0  |  P2 issues: 0  |  P3 notes: 30

Verdict: APPROVED

Top finding: closure is valid only over explicitly admitted typed relations
under one visible policy; transitive reachability over Markdown links or
lexical similarity is not Factorium composition.

Cross-role consensus: the query-induced working graph must remain local,
bounded, typed, deterministic, and traceable to canonical sources. `Complete`
and `evaluate` need especially narrow meanings, and the flattened guide must
retain an exact manifest so presentation never erases semantic alternatives,
contexts, exclusions, loss, or provenance.

## Phase 5 -- Amend

1. **ROADMAP R6 closure semantics:** add four exact closure states, finite
   traversal budgets, and visible frontier behavior so stopped work cannot be
   mislabeled as a fixed point.
2. **ROADMAP R6 operators and mappings:** declare arithmetic labels as UI
   shorthand and require explicit direction, arity, roles, qualifications,
   context, version, and loss for every traversed relation.
3. **ROADMAP and R5P custody:** require an embedded closure-trace manifest and
   classify queries and working graphs as noncanonical user work products with
   an explicit sensitivity and persistence policy.
