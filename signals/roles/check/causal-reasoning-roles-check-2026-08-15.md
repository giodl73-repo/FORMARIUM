# Causal Reasoning Roles Check

## Phase 1 - Artifact identification

Artifact type: canonical Factor Table anchor plus Evidence Table view, research
note, cross-reference repairs, and proposed interchange registration.

Domain signals: causal inference, evidence, statistics, experimental and
observational design, mechanisms, incident analysis, legal attribution risk,
reference architecture, and practitioner lookup.

## Phase 2 - Role selection

| Role | Why selected |
|---|---|
| Factorization Method Steward | Tests whether one causal framework is made inevitable. |
| Evidence & Claims Editor | Causal language creates unusually high overclaim risk. |
| Reference Lexicographer | Six nearby senses must remain quickly distinguishable. |
| Reference Architecture Editor | The new anchor bridges existing evidence and control authority. |
| Domain Source Reviewer | Formal and domain-specific causal methods retain scope. |
| Research Integrity & Provenance | Assumptions and evidence paths must be reconstructable. |
| Schema Implementer | New entry, sense, factor, and Evidence-view identities must be exact. |
| Reference Practitioner | The table must improve a real claim review without requiring formal specialization. |
