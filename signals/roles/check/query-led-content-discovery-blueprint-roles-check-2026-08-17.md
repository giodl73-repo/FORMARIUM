# Query-Led Content Discovery Blueprint Roles Check

## Artifact identification

Type: content-intake, reference-architecture, and product-investment proposal.

Domain signals: query design, canonical ownership, factorization, graph
closure, domain sources, synthetic evidence, publication custody, navigation,
and product value.

## Role selection

| Role | Why selected |
|---|---|
| Product Owner | The campaign must buy recognizable reader value rather than entries or phases. |
| Reference Practitioner | Questions and repairs must remain useful to a working reader. |
| Reference Lexicographer | Query friction must distinguish lookup, sense, synonym, and owner problems. |
| Reference Architecture Editor | New content must preserve one canonical reference and stable navigation. |
| Concept & Taxonomy Boundary Editor | Query-led discovery must not become member or proper-name enumeration. |
| Factorization Method Steward | Candidate factors need pivots, alternatives, dependencies, and stopping boundaries. |
| Compositional Semantics Steward | Query closure must preserve explicit senses, relations, ambiguity, and constraints. |
| Experimental Methodologist | Frozen prompts, nulls, and failed routes prevent favorable-example selection. |
| Domain Source Reviewer | Repeated wording alone cannot establish specialized domain content. |
| Research Integrity & Provenance | Baselines, packets, results, changes, and claims must be reconstructable. |

## Synthesis

Roles reviewed: 10

P1 blockers: 0 | P2 issues: 20 | P3 notes: 10

Verdict: APPROVED

Top finding: questions must be frozen before baseline execution, or content
admission will be biased toward gaps the author already expects to fill.

Cross-role consensus: query pressure earns investigation, not automatic
canonical content. Every proposed repair still needs one owner, the smallest
artifact test, source boundaries, baseline custody, and an explicit stop path.

## Amendments incorporated

1. Make the 24 packets a bounded, predeclared experimental portfolio rather
   than a content or coverage quota.
2. Add a gap taxonomy and ordered owner test that prefer discovery, senses,
   views, Guides, and external catalogs before new anchors.
3. Preserve exact `sim-41` custody, null results, failed routes, and the
   boundary between structural rehearsal and reader evidence.
