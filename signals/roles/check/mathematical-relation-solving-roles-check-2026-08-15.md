# Mathematical Relation and Solving Roles Check

## Phase 1 - Artifact identification

Artifact type: canonical Factor Table anchor, Diagnostic Table view, two
reassigned Formula Table owners, source review, graph-debt resolution, and
proposed interchange/book registration.

Domain signals: mathematical objects and notation, algebra, calculus,
numerical root finding, convergence claims, exact/approximate results, units,
provenance, and practitioner diagnostics.

## Phase 2 - Role selection

| Role | Why selected |
|---|---|
| Factorization Method Steward | Tests whether object, relation, solving, and numerical stages remain separable. |
| Experimental Methodologist | Audits numerical traces, initial conditions, stopping checks, and falsifiable convergence claims. |
| Evidence & Claims Editor | Prevents local or empirical solver behavior from becoming a universal theorem. |
| Benchmark Numeracy Checker | Audits iteration counts, tolerances, residuals, errors, rates, and denominators. |
| Reference Lexicographer | Common words such as function, equation, solution, root, and convergence need precise senses. |
| Reference Architecture Editor | Reassigns the final unresolved Formula views and connects software and measurement contrasts. |
| Domain Source Reviewer | Mathematical definitions and Newton conditions require authoritative sources and scope. |
| Research Integrity & Provenance | Symbolic transformations and numerical runs must be reconstructable. |
| Equation & Units Auditor | Audits symbol roles, domains, equality kinds, dimensions, derivatives, and approximations. |
| Reference Practitioner | Readers need a fast route from a suspicious result to a discriminating check. |
