# Synthetic User Job Discovery Plan Roles Check

## Artifact identification

Artifact type: synthetic product-research plan, frozen persona corpus, and
technical browsing experiment.

Domain signals: reference lookup, product positioning, synthetic personas,
search, experimental design, demographic descriptors, and usability-claim
boundaries.

## Selected roles

| Role | Why selected |
|---|---|
| Experimental Methodologist | Hypothesis, controls, thresholds, and null retention must be frozen |
| Data Split & Leakage Auditor | Task construction and persona metadata can leak intended outcomes |
| Reference Lexicographer | Dictionary/thesaurus comparison depends on sense and synonym boundaries |
| Evidence & Claims Editor | Synthetic reactions must not become reader evidence |
| Reference Practitioner | The proposed new reason must correspond to a useful reference job |
| Product Owner | Added research must clarify product value rather than produce persona theater |

## Synthesis

Roles reviewed: 6

P1 blockers: 0 | P2 issues: 0 | P3 notes: 18

Verdict: **APPROVED**

Top finding: commit the portfolio before execution so author-selected outcomes
cannot rewrite its composition.

Cross-role consensus: treat dictionary, thesaurus, and external authorities as
valid parts of the user journey. The campaign is valuable when it identifies
where Factorium continues that journey, not when it declares every alternative
inferior.

## Amendments applied

1. Freeze five lookup controls and four non-ordinal relationship classes.
2. Prohibit persona metadata from determining reactions or outcomes.
3. Bind every result to exact search evidence and label reactions as authored
   simulations rather than participant observations.
